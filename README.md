# suyihang15 WordPress Theme
一个简洁、大方的 WordPress 博客主题，为个人博客和作品展示设计。

## 特性
- 简洁现代的设计风格
- 响应式布局，支持移动端
- 可视化自定义设置，但就一些基础的（无需代码修改）
- 支持社交链接、个人简介展示
- 打赏功能，支持二维码上传
- 自定义颜色主题
- 支持评论、RSS 订阅（本人觉得RSS这的很好用）

## 安装
1. 下载主题文件
2. 上传到 `wp-content/themes/` 目录
3. 在 WordPress 后台激活主题

## 可视化设置
安装主题后，在 WordPress 后台的 **外观 > 自定义** 中可以进行以下设置：

### 社交链接设置
- QQ 号码
- 微信号
- 微信链接
- B 站主页链接
- GitHub 链接

### 备案设置
- ICP 备案号
- ICP 备案链接
- 公安备案号
- 公安备案链接

### 首页横幅
- 自定义首页顶部横幅文本（支持简单 HTML）

### 首页个人简介
- 首页封面图片
- 网站背景图片
- 简介标题、角色简介、个人简介
- 所在地、工作经验、技术栈

### 打赏设置
- 微信打赏二维码（上传图片）
- 支付宝打赏二维码（上传图片）
- 打赏说明文本，主要打赏方式就是二维码。

### 颜色设置
- 主色调
- 背景色

## 主题文件结构说明
这个主题的各个文件都有自己的作用，介绍一下就是：

- **README.md**：就是你现在看的这个文件，介绍主题怎么用、有什么功能。
- **style.css**：主题的“衣服”，决定网站看起来是什么样子，比如颜色、字体、布局等。
- **functions.php**：主题的“大脑”，里面写了很多代码，让主题能做各种事情，比如添加菜单、自定义设置、加载脚本、处理 AJAX 请求等。
- **index.php**：主题的默认模板文件，当没有更具体模板时使用，通常负责显示博客文章列表。
- **front-page.php**：首页模板文件，适用于设置为静态首页时，显示个人简介和文章列表。
- **home.php**：文章列表页模板，用于博客页面或“最新文章”页面。
- **single.php**：单篇文章页面的模板，打开一篇文章时用的。
- **page.php**：独立页面的模板，比如“关于我”“联系我”这样的页面。
- **header.php**：每个页面的顶部部分，包含网站标题、导航菜单、搜索框和社交链接等。
- **footer.php**：每个页面的底部部分，包含版权信息、备案号、RSS 链接等。
- **comments.php**：评论区的模板，显示评论列表和评论表单。
- **searchform.php**：搜索框的模板，用户搜索文章时使用。
- **assets/js/load-more.js**：前端脚本，支持“加载更多文章”的 AJAX 加载功能。
- **template-parts/**：模板部件文件夹，存放可复用的页面片段。
  - **template-parts/content-post.php**：文章列表中每一篇文章卡片的显示内容模板。
  - **template-parts/homepage-profile.php**：首页个人简介区块模板，显示封面图片、简介文字、个人信息。
  - **template-parts/post-list.php**：文章列表区块模板，统一处理文章循环和“加载更多”按钮。
- **inc/customizer.php**：自定义面板配置文件，定义外观 > 自定义中的设置项。

这些文件一起配合，形成主题的页面结构、样式和动态功能。
## 自定义菜单
主题支持自定义菜单。在 **外观 > 菜单** 中创建菜单并分配到“Primary Menu”位置。

## 特色图片
文章支持特色图片。在编辑文章时设置特色图片即可，这是我请我学美术的朋友帮我搞的。
